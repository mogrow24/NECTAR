# NECTAR 웹사이트 리뉴얼

NECTAR(넥타) — 프리미엄 글라스웨어/오브제 브랜드(주식회사 아르피노)의 웹사이트(nectarofficial.com) 리뉴얼 디자인 작업.
실제 구현은 **Cafe24** 기반(커스터마이징 한계 감안). 디자인 시안은 Figma에서 관리.

## 🔗 디자인 (Figma)

- 파일: **넥타** — https://www.figma.com/design/CkPN96MF2I85qajx4WpiLI/
- 리뉴얼 작업은 Figma 내 **"리뉴얼" 페이지**에 정리되어 있음.

| 섹션 | 내용 |
|------|------|
| 피드백 정리 (PC · 모바일) | 아래 피드백 항목을 카드로 정리 |
| 풀 리디자인 v3 (PC, 1440px) | HOME · SHOP(전체상품) · PDP(상품상세) · ABOUT(브랜드 소개) |

- 상품명·가격·이미지는 **실제 사이트 데이터** 적용. PDP는 실제 상세 페이지 구조 참고.

## 🎨 디자인 원칙 (톤앤무드)

- **컬러**: Red `#C7172A` · Black `#111` · Cream `#F4F2EE` · White
- **타이포**: Playfair Display(브랜드/영문 헤드라인) · Noto Sans KR(본문) · Noto Serif KR(브랜드 선언문)
- **스타일**: 각진(라운드 0) · 미니멀 · 여백 중심 · 균일 상품 카드(동일 오브제 기준선)
- **모바일**: 기본 해상도 **375px**, **반응형(적응형 아님)** — 오토레이아웃 + FILL 구조

## 📝 피드백 / 수정사항

### PC (데스크탑)
1. **사이트 정체성** — 브랜드 소개 vs 판매 사이트가 어중간. 지향점(브랜드/큐레이션/판매) 명확히. 참고: Pedestal, OUTFIT.
2. **구매·결제 UX** — 비회원 바로구매·결제 모달, 회원정보 자동입력, 예치금↔적립금 설명 + 환불/전환 선택, 약관 일괄동의.
3. **팝업** — 화면 중앙·크게·토스트 스타일, 버튼 크게 '반반'.
4. **상품 그리드** — 오브제 크기·위치 통일, 제품명 고정 여백(겹침 방지).
5. **네비·타이틀** — 상단 메뉴바 + "이달의 인기 제품" 등 섹션 타이틀로 정체성·신뢰감.
6. **재생 버튼** — 애매한 버튼 숨김 또는 "브랜드 필름" 명확 라벨.
7. **디자인 톤** — 각진 스타일, 레드·블랙·크림, 전체 통일감, 픽셀 정렬.
8. **플랫폼/콘텐츠** — Cafe24 한계 감안, 실제 콘텐츠·이미지·가격 적용.

### 모바일
1. **기본 해상도** — 375px (Cafe24 모바일 기준).
2. **반응형 구조** — 적응형 아님. 오토레이아웃 + FILL로 폭 변화에 자동 리플로우.
3. **레이아웃** — 2단 상품 그리드, 가로 스크롤 카테고리 칩.
4. **PDP** — 상품 소개/사이즈/리뷰 탭(스크롤 이동), 영상 자리(브랜드 필름 스틸), 하단 고정 구매바.
5. **공통** — 실제 콘텐츠·이미지, PC와 동일 톤앤무드.
